# PURO HUMO

Plataforma web para la gestión de grupos, retos, puntos, subastas e historial del evento.

## Estado del proyecto

Esta versión es un prototipo de interfaz. Utiliza almacenamiento local del navegador (`localStorage`) y todavía no está conectada a una base de datos compartida ni cuenta con autenticación segura.

## Próximos pasos

- Conectar Supabase para autenticación y persistencia compartida.
- Implementar roles y permisos para participantes y administradores.
- Validar en el servidor las asignaciones de puntos, solicitudes, pujas y adjudicaciones.
- Probar la seguridad antes de utilizarla con participantes reales.

## Desarrollo

La página inicial está en `index.html` y puede abrirse directamente en un navegador.
